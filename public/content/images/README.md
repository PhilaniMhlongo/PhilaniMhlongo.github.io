# Images Directory

Place your images here to use in markdown files.

## Usage

In your markdown files, reference images like this:

```markdown
![Alt text description](/content/images/your-image.png)
```

## Supported Formats

- PNG
- JPG/JPEG
- WebP
- SVG
- GIF

## Best Practices

1. **Optimize images** before uploading (recommended max width: 1200px)
2. **Use descriptive filenames** (e.g., `kubernetes-architecture.png`)
3. **Always include alt text** for accessibility
4. **Consider file size** - compress large images

## Example

Place `devops-pipeline.png` in this directory, then use:

```markdown
![DevOps CI/CD Pipeline](/content/images/devops-pipeline.png)
```
